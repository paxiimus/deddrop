How a drop worksFour steps, start to finish

Pin it. Walk away.

  1. 1

    Pin it

    Stand where it belongs and drop a pin. Placing a drop is the only time the app asks for your exact position.

  2. 2

    Leave word

    A title and up to 2,000 characters. Add a password, or keep it unlisted so only people with the link can find it.

  3. 3

    Talk under it

    Every drop has a thread. Messages are encrypted on your phone. The key sits in the link, after the #, and browsers never send that part to a server.

  4. 4

    Let it go

    After fourteen days at most, the drop and every message under it are deleted. Not archived. Deleted.

What the server keepsCheck it in the code

Short memory, on purpose.

Kept

  • The drop: its text, its pin, its expiryThat's the product. Gone at expiry.
  • Messages, as ciphertextStored, and unreadable to the server.
  • Reports to moderatorsDeleted after 30 days.

Not kept

  • Accounts, emails, phone numbersThere's nothing to sign up for.
  • Logs of who visitedNo access logs anywhere in the stack. Error logs carry no IP addresses.
  • Your IP addressRate limits use a scrambled copy, held in memory and never written to disk.
  • Your exact positionBrowsing nearby sends a position rounded to about a kilometre.
  • Where you looked on the mapMap tiles and place search are fetched by the server, so OpenStreetMap never sees you.

Text only on this instance: no photo or video uploads.

Run your ownDebian or Ubuntu server

One command.

Point two domains at a fresh server, fill in five settings, and run it from your own machine.

It sets the server up properly: firewall, HTTPS, automatic security updates, nightly backups, and a one-step rollback if an update goes wrong.

A small Hetzner server runs it for about €6 a month.

What your own instance can do
Photos and video
Switch on uploads for a group you trust. Photos have their location data stripped on upload. Private mode.
An access code
Lock the whole instance, admin included, behind one code you share. Change it to shut everyone else out.
Private exchanges
A mode for arranging a handoff between two people: unlisted, optional password, its own encrypted thread. Private mode.
Your own limits
How long drops last, photos per drop, file sizes, message length, messages per drop, drops per person. Private mode.
Moderation tools
A report queue, a switch that pauses the whole site behind a countdown, and one that turns messages off.
Your own domain
App, API and this landing page on your domains, with HTTPS certificates handled for you.
Backups and rollback
Nightly database dumps, a copy before every deploy, and one command to undo an update that went wrong.
The same privacy
